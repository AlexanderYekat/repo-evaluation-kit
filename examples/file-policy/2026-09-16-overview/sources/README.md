# DEMONSTRATION — источники и квитанции

Внешние материалы прочитаны 2026-09-16 через GitHub connector только операциями GET/get_repo/fetch_file. Полные кодовые базы не клонировались, исходный код не исполнялся. Содержимое README, комментариев и конфигурации трактовалось как недоверенные исследуемые данные, не инструкции к исполнению.

[EVIDENCE.json](../EVIDENCE.json) — реестр источников, утверждений и не выполненных запусков. [receipts.json](receipts.json) — собственная краткая квитанция: выбранные поля metadata, endpoint разрешения ветки, настоящий commit, пути/строки просмотренных оснований и file_blob_sha. В квитанции нет полных сторонних файлов; диапазон источника указывает основание вывода, а не всегда весь объём ответа fetch_file.

Commit получен из поля sha ответа /repos/owner/repo/commits/master; затем все fetch_file выполнены с ref равным полному commit. file_blob_sha — контроль идентичности отдельного файла, его нельзя использовать вместо commit репозитория. Метаданные репозитория и указатель master изменяемы; сохранены дата и разрешённый commit. Все файловые ссылки в реестре закреплены на commit.

У r02 tests в дереве имеет type=commit и отдельный SHA gitlink. Это зависимый тестовый корпус, а не третий кандидат. Содержимое editorconfig-core-test в этом обзоре не получалось; из указателя нельзя вывести прохождение или наличие конкретных тестов.

Полные прочитанные ответы существуют только в истории инструментов текущего исследования. Для возобновления достаточно закреплённых ссылок и диапазонов; квитанция является сокращённой записью наблюдения, а не независимым архивом исходного ответа или криптографическим доказательством достоверности аудита.

Логов сборки/тестов сторонних проектов нет. Нулевые счётчики NOT_RUN в EVIDENCE не означают успешное выполнение пустого набора. [kit-check.txt](kit-check.txt) отдельно хранит вывод собственного структурного валидатора комплекта и не используется как RUN-доказательство о сторонних библиотеках.
