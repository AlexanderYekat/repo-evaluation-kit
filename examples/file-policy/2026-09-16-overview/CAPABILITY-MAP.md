# DEMONSTRATION — возможности относительно цели

**OVERVIEW.** Сопоставление основано на [EVIDENCE.json](EVIDENCE.json), не на рейтинге популярности. Статус связи: **PROPOSED_INTEGRATION**. Предлагаемая совместная работа пока INFERENCE, её выполнение NOT_RUN.

- **C1, отбор файлов по ignore-правилам:** r01 — предполагаемый основной движок; c01-purpose (документация), c01-engine (исходники), c01-role (применимость). Для r02 эта роль не обоснована. Остаток: область действия ignore-файлов и обход дерева.
- **C2, эффективные правила оформления:** r02 — предполагаемая подсистема; c02-engine подтверждает основной путь в исходниках. Для r01 эта роль не обоснована. Остаток: проверки glob/unset, Windows и границы чтения.
- **C3, нарушения и отчёт без исправлений:** у выбранных entrypoints готовая общая функция не установлена (c01-unknown). Предлагается собственный небольшой слой проверки содержимого и отчётности; отсутствие такого компонента во всех файлах обоих проектов не доказано.
- **C4, понятная композиция и ошибки:** отдельные API найдены; совместимость — гипотеза. Для r02 c02-io показывает подавление OSError, поэтому нужен способ отличать отсутствие политики от ошибки доступа.
- **C5, окружение и условия использования:** требования обоих манифестов найдены (c01-runtime, c02-runtime), но установка NOT_RUN. В обоих проектах документы о лицензиях содержательнее одной метки API/манифеста (c01-license, c02-license).

Репозитории **дополняют друг друга** в предложенной архитектуре: один определяет кандидатов на проверку, второй — эффективные свойства оформления. Наличие реальной зависимости друг от друга не установлено. Стрелка r01 → r02 означает предлагаемую передачу путей в собственном приложении, не найденную интеграцию.

Взять как зависимости предлагается matcher r01 и API свойств r02; адаптировать нужно границы и ошибки; создать самому — проверки ограниченного набора свойств и отчёт. Использовать внутренние backend классы как устойчивый публичный контракт не предлагается.

Альтернатива при запрете Python — пересмотр кандидатов; в рамках двух входов она не проверялась. Изменять исходную цель или объявлять Python обязательным нельзя.
