# DEMONSTRATION — локальная проверка файлов

Дата: 2026-09-16. Глубина: **OVERVIEW**, первичный статический обзор двух публичных репозиториев. Это выполненный пример применения методики, а не шаблон и не глубокий аудит.

## Цель и вход

[Исходный минимальный запрос](request.json): получить локальный отчёт о нарушениях файловой политики, учитывать ignore-правила и правила .editorconfig, не изменять проверяемые файлы и не создавать оба движка правил с нуля.

Кандидаты: cpburnz/python-pathspec и editorconfig/editorconfig-core-py. Выбраны исследователем для небольшого сценария вне 1С. Оба входа учтены, недоступных и дубликатов нет. Версии — в [INVENTORY.json](INVENTORY.json).

## Критерии применимости

- C1: определить, подлежит ли относительный путь проверке, по переданным ignore-правилам; отдельно проверить смысл отрицаний и порядок правил.
- C2: получить эффективные свойства .editorconfig для абсолютного пути с учётом вложенности и root=true.
- C3: сопоставить свойства с содержимым, выдать понятный отчёт и не изменить входное дерево.
- C4: иметь понятный интерфейс для композиции; отделять ошибку чтения политики от отсутствия правил.
- C5: установить требования окружения и документы об условиях использования до принятия зависимостей.

## Ограничения и предположения

Разрешено читать публичные метаданные, документацию и отдельные файлы по закреплённому commit. Не разрешено клонировать кодовые базы, устанавливать зависимости и выполнять сторонний код. Эти ограничения взяты из задания на демонстрацию, а не выведены из минимального request.json.

Окружение будущего продукта пользователь не выбрал. Python рассматривается потому, что оба кандидата предоставляют Python API; это архитектурная гипотеза, не универсальное требование. Конкретную версию Python и ОС предстоит выбрать для эксперимента.

Для первого эксперимента исследователь предлагает один явно переданный набор ignore-правил и небольшое дерево с .editorconfig. Это ограничение эксперимента, а не утверждение, что задача с вложенными ignore-файлами решена. Исправление файлов, интерфейс редактора, масштабирование и benchmark вне объёма.
