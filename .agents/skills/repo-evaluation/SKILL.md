# Исследование репозиториев относительно цели

Вход: человеческое описание цели и ссылки; дополнительный контекст необязателен.
Результат: доказательные карточки, общая картина пользы, ограничения и следующий
проверяемый эксперимент в отдельном каталоге. Заполнение шаблонов само по себе
не является исследованием: прочитай реальные доступные материалы кандидатов.

## Маршрут

1. **START-AUDIT** (также обычный запрос с целью и ссылками): прочитай
   [методику](references/methodology.md). Переведи запрос в краткий brief,
   не требуя анкеты. Для сохранения данных прочитай
   [форматы](references/formats.md). Создай отдельный каталог, зафиксируй вход,
   затем выполни этапы А–Е до согласованной глубины.
2. **CONTINUE-AUDIT**: сначала `STATE.md` указанного исследования, затем
   [продолжение](references/continuation.md). Восстанови версии, критерии,
   незакрытые проверки и полномочия из файлов. При запросе углубления выбранных
   кандидатов используй раздел «Углубление выбранных репозиториев» в продолжении.
   Не начинай заново весь аудит.
3. **REASSESS-GOAL**: прочитай [продолжение](references/continuation.md),
   сохрани прежнюю цель и решения, сопоставь изменившиеся критерии с фактами.
   Новая платформа может менять способ достижения результата; изменение самой
   цели или обязательных ограничений требует решения пользователя.

Подключай шаблон только при подготовке соответствующего результата:
[brief](assets/BRIEF.md), [карточка](assets/REPOSITORY.md),
[матрица](assets/CAPABILITY-MAP.md), [общий отчёт](assets/REPORT.md),
[проверки](assets/VALIDATION.md), [состояние](assets/STATE.md).
Машинные заготовки: [вход](assets/request.minimal.json),
[реестр](assets/INVENTORY.json), [доказательства](assets/EVIDENCE.json).

## Инструменты и границы

Используй имеющиеся файловые инструменты, браузер, API или CLI для реального
чтения. При ограниченном доступе запиши проверенный объём и неизвестное;
не выдумывай команды, ответы сети, commit или результаты исполнения.
Полномочия и правила недоверенных материалов определяет раздел «Границы» методики.

Необязательный [kit.py](scripts/kit.py) работает на Python 3.10+ без зависимостей:
`validate-request`, `init`, `check-run`, `check-kit`.
Точные команды находятся в [форматах](references/formats.md).
Скрипт создаёт заготовки и проверяет согласованность, но не читает репозитории
и не делает выводы за аудитора. Без Python создай те же файлы вручную.

Все пути здесь относительны каталогу этого skill. Исходный пример и настройки
конкретного компьютера не требуются. Другой coding-агент может напрямую прочитать
методику и продолжение, не поддерживая формат skills.
