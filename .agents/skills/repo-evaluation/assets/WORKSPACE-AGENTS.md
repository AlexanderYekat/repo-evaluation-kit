# Исследовательское рабочее пространство

Это проект одной цели, не исходники комплекта repo-evaluation-kit.
Для запуска следуй README: цель и ссылки поступают из сообщения или request.json.
Исследование выполняй в отдельном каталоге evaluations/.
Результаты в evaluations/ — рабочий продукт этого проекта; копии исходников
кандидатов в git не входят.
Для исследования кандидатов используй [repo-evaluation](.agents/skills/repo-evaluation/SKILL.md).
Единый источник содержательных правил — его `references/methodology.md`;
форматы и механика — `references/formats.md`.

Новые запуски создаются отдельно, не внутри шаблонов skill.

Не создавать commits, push, PR, удалённые репозитории, глобальные установки
или изменения пользовательских настроек без отдельного задания.
