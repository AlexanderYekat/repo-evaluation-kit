# Проверки и следующий эксперимент

Заготовка. До исполнения сценарии имеют NOT_RUN; это план, не результаты.
Основания и протоколы: [EVIDENCE.json](EVIDENCE.json).

## Общий проверочный корпус

Для сравнимых кандидатов: C*, входы/версия корпуса, независимый ожидаемый результат,
положительный, отрицательный и пограничный случаи, единые метрики/условия.
Для разных ролей сравнивай соответствующий контракт, а не искусственный общий балл.

## План и фактические результаты

Для каждой проверки: ID, вопрос, кандидат/commit, приоритет и причина,
ожидание, статус PASS/FAIL/NOT_RUN/BLOCKED, ID запуска и причина/блокировка.
Раздельно: статическое чтение, сборка, поведение, интеграция, измерение.

## Следующий ограниченный эксперимент

Вопрос/гипотеза: … Выбранные версии: … Вход и эталон: …
Среда и необходимые разрешения: … Шаги/команды: …
Наблюдаемый PASS: … Наблюдаемый FAIL: … Отрицательный контроль: …
Ограничение времени/данных и условие остановки: …
Решение после каждого исхода: … Исполнитель/артефакт: …

При запуске сохрани время, версии, команду, expected/actual, exit code,
число реально выполненных проверок, skips/mocks и обезличенный лог в `sources/`.
После предложения эксперимента не начинай его без задания и нужных разрешений.
