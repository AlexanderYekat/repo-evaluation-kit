## Матрица

Создай компактную матрицу или список: критерий C* → кандидат/роль → покрытие
(полное/частичное/не установлено в проверенном объёме) → ID доказательства →
готовность → недостающая проверка. Неприменимое пометь с причиной, не ставь ноль.
Не складывай полезность, готовность и доказанность в одно число.

PROPOSED_INTEGRATION / VERIFIED_INTEGRATION, основание и ограничения.
