# START-AUDIT

Прочитай [skill](../.agents/skills/repo-evaluation/SKILL.md) и выполни START-AUDIT
по следующему запросу: «Цель: … Репозитории: …».
Необязательный контекст: текущие решения, ограничения, глубина, разрешения,
желаемый каталог результата. Либо используй приложенный request.json.

Работай по методике skill, изучи реальные материалы каждого входного кандидата,
сохрани отдельное исследование и заверши человеческим ответом и следующим
ограниченным экспериментом. Необязательные сведения не требуют анкеты перед чтением.
