# repo-evaluation-kit

Помогает выбрать репозитории под вашу задачу: что взять готовым, что адаптировать,
чего не хватает и что проверить следующим шагом. Исследование выполняет агент Codex
по вашим цели и ссылкам.

**Один проект — одна ваша цель и все репозитории-кандидаты для неё.** В примерах
ниже они исследуются вместе в `evaluations/main/`. У каждого репозитория будет
своя карточка в `reports/`, а общий отчёт сопоставит их пользу для вашей цели.
Обзор и последующее углубление продолжаются в этом же каталоге.

## Как начать

1. Откройте эту папку как проект в Codex и создайте чат.
2. **Напишите цель и ссылки прямо в чат.** Скопируйте сообщение ниже и замените
   текст в квадратных скобках своими данными.
3. Отправьте сообщение. Агент изучит репозитории и сохранит результаты в файлы.

```text
Прочитай .agents/skills/repo-evaluation/SKILL.md и выполни исследование.

Моя цель: [опишите, какой результат хотите получить и что не хотите писать с нуля].

Репозитории:
- [ссылка на первый репозиторий]
- [ссылка на второй репозиторий]

Начни со статического обзора всех кандидатов.
Результаты сохрани в evaluations/main.
```

Например, цель: «Хочу локальный инструмент проверки оформления файлов.
Нужно учитывать ignore-правила и .editorconfig; не хочу писать оба движка с нуля».
Ссылки для такого исследования:
[python-pathspec](https://github.com/cpburnz/python-pathspec) и
[editorconfig-core-py](https://github.com/editorconfig/editorconfig-core-py).

В цели можно указать ограничения: язык, ОС, работу без интернета, нежелательные
зависимости. Если их нет, достаточно желаемого результата и ссылок.
По умолчанию агент читает документы и код. Сборки, установка зависимостей и запуск
исследуемых программ требуют соответствующего разрешения.

## Как заказать глубокое исследование

Если общий обзор уже есть, отправьте в тот же или новый чат проекта:

```text
Прочитай .agents/skills/repo-evaluation/SKILL.md.
CONTINUE-AUDIT: каталог evaluations/main.

Проведи глубокое исследование кода (deep-static) этих репозиториев:
- [ссылка или ID репозитория из реестра]
- [ещё одна ссылка или ID, если требуется]

Используй сохранённую цель проекта. Проследи ключевые сценарии по коду,
проверь реализацию важных возможностей, ошибки, заглушки и ограничения.
Обнови карточки выбранных репозиториев, общие выводы и STATE.md.
```

**Для одного репозитория оставьте одну строку, для нескольких — перечислите их.**
Для всех замените список фразой «Углублённо исследуй все репозитории из реестра».
Остальные кандидаты сохраняют свои карточки и достигнутую глубину проверки.
Если ранее был обещан глубокий аудит всего списка, его оставшиеся проверки
сохраняются в плане.

Можно сразу начать с глубокого исследования: в первом сообщении укажите цель,
нужные ссылки и вместо «Начни со статического обзора» напишите
«Проведи глубокое исследование кода (deep-static) всех перечисленных репозиториев».

`deep-static` — подробное чтение реализации и проверка выводов по исходникам.
Сборки и тесты относятся к режиму `execution`: для них укажите разрешённые действия
и тестовое окружение. Например: «Дополнительно разрешаю получить исходники,
установить зависимости, собрать и запустить тесты выбранных репозиториев в отдельном
тестовом каталоге. Запуски и результаты сохрани в исследовании».

## Где читать результат

Для сообщения выше откройте папку `evaluations/main/`:

- `REPORT.md` — главный ответ: что использовать, ограничения и следующий шаг.
- `reports/` — разбор каждого репозитория.
- `CAPABILITY-MAP.md` — какие требования закрывает каждый кандидат.
- `STATE.md` — что сделано и с чего продолжить.

Агент сохраняет здесь же цель, критерии и ссылки на проверенные версии кода.
Если исследование уже лежит в другом каталоге, укажите в сообщении его фактический путь.

## Если удобнее записать цель и ссылки в файл

Скопируйте [request.example.json](request.example.json) в `request.json` в корне
этой папки. Отредактируйте **`goal` — ваша цель** и **`repositories` — список ссылок**.
Остальные поля необязательны. Затем отправьте в чат:

```text
Прочитай .agents/skills/repo-evaluation/SKILL.md.
Входные данные возьми из request.json в корне проекта.
Выполни статический обзор и сохрани результат в evaluations/main.
```

Для глубокого исследования всех репозиториев из этого файла добавьте поле
`"depth": "deep-static"` и в сообщении попросите выполнить исследование по
указанной в файле глубине. Углубление части уже изученного списка заказывайте
через CONTINUE-AUDIT выше, с указанием нужных репозиториев.

Это полноценный запуск исследования агентом. Вспомогательный Python-скрипт
только создаёт заготовки и проверяет файлы; сам репозитории он не исследует.

## Как продолжить или изменить цель

В новом чате этого проекта отправьте:

```text
Прочитай .agents/skills/repo-evaluation/SKILL.md.
CONTINUE-AUDIT: продолжи исследование evaluations/main по STATE.md.
```

Чтобы пересмотреть уже изученные кандидаты:

```text
Прочитай .agents/skills/repo-evaluation/SKILL.md.
REASSESS-GOAL: каталог evaluations/main.
Новая цель: [новый желаемый результат]. Сохрани прежние решения в истории.
```

## Использование в другом проекте

Скопируйте весь каталог `.agents/skills/repo-evaluation/` в `.agents/skills/`
другого проекта. Откройте тот проект в Codex и используйте те же сообщения.
Методика, шаблоны и скрипт входят в каталог skill.

